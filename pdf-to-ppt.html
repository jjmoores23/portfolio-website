PDF to PowerPoint

Upload a PDF to create a PowerPoint slideshow with one image-based slide per page. Add presenter comments for each page and download a presentation ready to open in Microsoft PowerPoint.

The first version supports PDFs up to 16 MB and 50 pages. Your PDF pages become slide images so their visual layout is preserved.

Choose a PDF to begin.

Presenter comments

After the PDF pages load, a notes field will appear for each slide. These comments are stored in PowerPoint's presenter notes, not printed over the slide image.

Presenter comments

Add optional comments for each slide. Blank fields remain blank in the downloaded presentation.
